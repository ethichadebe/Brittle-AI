# 2026-09-16 — Onboard to Mobile Delivery

- **Asked for:** onboard this repository to Mobile Delivery — conventions in `CLAUDE.md`, shared checks in `.github/workflows/ci.yml`, this journal, and the plugin declaration in `.claude/settings.json`.
- **Worked first time:** yes, but only after two things had to be worked out by reading the repo rather than copying the example. The example calls the shared checks once per folder; this repo is an npm workspaces monorepo with one lockfile at the root, so `npm ci` inside `frontend/` or `backend/` would have failed and every job had to install from `.` and scope its command with `-w`. And the backend does not typecheck or build at all until `npm run db:generate -w backend` has generated the Prisma client, so that job's install step had to be overridden.
- **Laptop needed:** no. Everything was installed, typechecked, built and tested in the cloud session before the pull request was opened.
- **Friction:**
  - The backend test suite cannot run in CI. It connects to a real Postgres (`globalSetup.ts` fails with `P1001` without one) and expects the migrations already applied, and the shared Node checks have no database service. The command exists and is genuinely useful locally, so it is documented in `CLAUDE.md` and left out of the workflow rather than wired up red.
  - There is no linter anywhere in the repo — no ESLint, no Prettier, no `lint` script. The `lint` slot runs each Target's `typecheck` instead, which is honest about what it does but means "lint passed" means less here than it looks.
  - `npm run build -w frontend` is `tsc && vite build`, and `frontend/tsconfig.json` sets neither `noEmit` nor `outDir`, so the `tsc` half scatters compiled `.js` files next to the sources in `frontend/src/`. They are untracked and not gitignored, so a local build leaves thirteen files sitting in `git status` waiting to be committed by accident, and Vite warns about duplicate route files on the next build. It is harmless on a fresh CI checkout, so it was left alone rather than widening this pull request, but it is a trap for anyone running the checks locally as `CLAUDE.md` now asks them to.
